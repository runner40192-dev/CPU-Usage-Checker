# CPU-Usage-Checker
C Program to Check CPU Usage (Shows all currently running Process On Your PC)
This is is program I made in C that shows what is running on your CPU. It also shows the process ids (PIDs) for each program running on your pc and the CPU time. The CPU time is the total active duration your processor spends executing instructions for a file to run. This excludes the waiting time for disk read/write time, network requests, and at rest states. To run the program inside of Penguin Linux type gcc CPUuse.c -o cpu_usage then click enter. Next type ./cpu_usage and click enter.
